# 🚀 Thiranex TaskFlow – To-Do List

A simple and interactive **To-Do List Web Application** developed as part of **Thiranex Task 3 – JavaScript Logic & State Management**.

The project demonstrates JavaScript DOM manipulation, event handling, CRUD operations, filtering, and browser localStorage.

## 🌐 Live Demo

🔗 https://sripriyamallari.github.io/thiranex-task3-todo-list/

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks by:
  - All
  - Active
  - Completed
- 💾 Save tasks using browser `localStorage`
- 🔄 Tasks remain available after refreshing the browser
- 📱 Responsive design for mobile and desktop
- 🧹 Clear completed tasks

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser LocalStorage
